# Definition of Done

Задача (Issue) считается выполненной, только если выполнены **все** пункты ниже.
Если какой-то пункт неприменим (например, в задаче нет кода), это нужно явно написать в PR.

- [ ] Код попал в `main` через Pull Request (не напрямую)
- [ ] PR прошёл review: есть минимум одно одобрение от другого участника
- [ ] Проект собирается и запускается после изменений
- [ ] Тесты проходят (если в проекте есть тесты); для новой логики добавлены тесты, если это применимо
- [ ] Документация обновлена: README, wiki или `docs/`, если изменилось поведение, API или способ запуска
- [ ] Все критерии приёмки из Issue выполнены и отмечены
- [ ] В коде нет секретов, ключей, паролей и личных данных
- [ ] Issue закрыт (автоматически через `Closes #N`), карточка на доске в статусе **Done**

## Для задач дизайна

- [ ] Макет лежит в Figma в правильном файле и на правильной странице (см. [FIGMA_GUIDE](https://github.com/study-ai-assistant/mobile/blob/main/docs/FIGMA_GUIDE.md))
- [ ] Ссылка на фрейм добавлена в Issue
- [ ] Макет прошёл чек-лист «макет готов» и просмотрен разработчиком mobile
