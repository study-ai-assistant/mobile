## Найденная проблема окружения

В Windows настроен системный прокси. Прямое соединение Java с Groq возвращало
403, а обращение с настройками системного прокси — 200. Backend скрывал ошибку
провайдера за ожидаемым ответом 502. Исправлен способ локального запуска:

```powershell
java -Djava.net.useSystemProxies=true -jar target/backend-0.0.1-SNAPSHOT.jar
```

Исходный код backend для этого не менялся. Команда использует уже существующие
настройки сети Windows; не настраивает новый прокси. На другом компьютере
доступ к провайдеру нужно проверить отдельно.
