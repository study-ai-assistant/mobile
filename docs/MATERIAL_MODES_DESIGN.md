# Загрузка материала и выбор режима — #35

Основа: присланные макеты загрузки/выбора режима и UI-kit (JetBrains Mono,
цвета существующей темы). Финальная визуальная приёмка дизайнером ещё требуется.

- Загрузка: приветствие, карточка добавления материала, TXT-файл с именем и
  удалением, поле текста со счётчиком Unicode-символов, кнопка выбора режима.
- Файл читается вне UI-потока, с пределом 10 МиБ. Показан индикатор без вымышленного
  процента. Пустой файл и ошибки доступа объясняются; прежний материал сохраняется.
- После выбора файла текстовое поле неактивно. Удаление файла возвращает ручной ввод.
- Пустой/пробельный текст и текст длиннее 10 000 символов не отправляются.
- Режимы загружаются с сервера: карточки с русским названием, описанием и отметкой
  выбора. При ошибке загрузки доступен повтор. Во время обработки выбор заблокирован.
- Отступы, высоты, формы и цвета взяты из темы. На маленьком экране содержимое
  прокручивается; кнопки доступны при открытой клавиатуре.
- Настройки адреса сервера и проверка связи сохранены ниже основной формы.

## Граница с задачей #32

к StudyApi. Здесь восстановлен TXT по работающему контракту. PDF добавляет отдельный
PR Арсения (#32): при объединении сохранить MaterialContent, безопасное чтение
через readFile/Dispatchers.IO и callback uploadTxt; расширить проверку формата и
список MIME, а не заменять MainActivity старой версией.

выбор/удаление файла, доступность пяти режимов, переходы, результат, отмена,
