## Ошибки

Для каждой ошибки: версия APK, модель/Android, шаги, ожидание, факт, скриншот.
Отдельный Issue по шаблону «Ошибка», label bug; Urgent — ломает основной сценарий/демо, Medium — заметно, но не мешает.
Резервы исправлений: #75 (Глеб), #77 (Артём). Не закрывать их автоматически одним PR документации.
