# Ожидание, ошибки и повтор запроса

Задача: mobile#22.

- Во время обработки видны индикатор и название режима. «Создать» неактивна;
  повторное нажатие не отправляет второй запрос.
- Через 20 секунд появляется пояснение о долгом ожидании. Оно не запускает повтор.
- Таймаут чтения ответа обработки — 90 секунд. Подключение и проверка `/health`
  используют короткий таймаут 10 секунд. Значения находятся в `api/ServerConfig.kt`.
- Ошибки отображаются на текущем экране; автоматических повторов нет.
- «Повторить» повторяет неудачный запрос: сохраняются его текст и режим.
  Повтор проверки связи вызывает только `/health`, без обработки текста.
- Редактирование материала, смена режима или возврат сбрасывают возможность
  повторить прежнюю ошибку. «Создать» отправляет уже новое содержимое.
- «Отмена» завершает ожидание в приложении. Сервер может продолжать обработку;
  поздний ответ не заменяет состояние следующего запроса.

## Сообщения

| Причина | Что видит пользователь |
|---|---|
| Нет соединения | Не удалось связаться с сервером. Проверьте подключение к сети и попробуйте снова. |
| HTTP 400 | Сервер отклонил запрос. Проверьте текст и выбранный режим. |
| HTTP 413 | Материал слишком большой для сервера. Сократите текст или выберите файл меньшего размера. |
| HTTP 502 | Сервис обработки текста временно недоступен. Попробуйте позже. |
| Таймаут | Сервер не ответил вовремя. Попробуйте ещё раз позже. |

Сообщения заданы в `api/ApiMessages.kt`. Внутреннее тело ошибки сервера
не выводится пользователю. Упоминание файла в сообщении 413 не включает
загрузку TXT: она реализуется отдельно в mobile#21.

## Проверка

```powershell
.\gradlew.bat assembleDebug testDebugUnitTest lintDebug
.\gradlew.bat connectedDebugAndroidTest -Pandroid.testInstrumentationRunnerArguments.class=ru.studyassistant.mobile.StudyFlowUiTest
```

Для второй команды нужен запущенный эмулятор или подключённый телефон.
Unit-тесты проверяют конкретные сообщения HTTP/сети/таймаута, настройки таймаутов,
содержимое повторного запроса, отсутствие двойной отправки и игнорирование позднего ответа.
Таймаут воспроизводится подменой соединения без ожидания 90 секунд.
UI-тесты используют тестовые ответы: настоящий backend и ключ LLM не требуются.

Вручную: отправить текст, убедиться, что «Создать» неактивна во время ожидания;
при отключённом сервере проверить сообщение и «Повторить» после его запуска.
После успешного ответа должен открыться результат.
