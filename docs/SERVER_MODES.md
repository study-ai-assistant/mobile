# Режимы сервера (mobile#19)

При переходе к выбору режима клиент загружает GET /api/v1/modes.
Ответ — массив строковых идентификаторов. Названия и короткие описания заданы
в ProcessingMode. Неизвестные идентификаторы пропускаются; пустой список
поддерживаемых режимов считается ошибкой. Ошибку можно повторить кнопкой
«Загрузить режимы снова». До получения списка отправка текста недоступна.

POST /api/v1/text/process передаёт выбранный идентификатор. Заголовок результата
сохраняет режим выполненного запроса. Все пять идентификаторов проверяются
unit-тестами и HTTP-сервером-заглушкой.

Перед закрытием Issue отдельно проверить все пять режимов с настоящим backend
и LLM: подготовить текст, выбрать каждый режим, получить непустой ответ и
проверить подпись результата. Сервер должен содержать реализацию backend#18.
Зелёные тесты с заглушкой не заменяют эту проверку.
