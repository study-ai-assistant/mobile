# Тема Compose — mobile#23

Источник: UI-kit «палитра цветов и стили текста», переданный 01.11.2026.
[Figma](https://www.figma.com/design/mfGaM00iqFy7L5DzTJn1K2/?node-id=1-3).
При расхождении с иллюстрациями экранов используются подписанные HEX-коды UI-kit.

| Роль | HEX |
|---|---|
| Основной цвет | #7C3AED |
| Неактивная кнопка | #B997F5 |
| Фон карточек и полей | #E8E2FF |
| Фон приложения | #F5F4FE |
| Основной текст | #1F1A3E |
| Второстепенный текст | #4B3F72 |
| Текст на основной и неактивной кнопке | #FFFFFF |
| Текст ошибки | #D94B78 |
| Фон ошибки | #EEC1D5 |
| Успех (доступен в теме) | #90E0AE |

Палитра находится в `ui/theme/Color.kt`, роли Material — в `Theme.kt`.
Для специальных неактивных цветов используется `StudyButton` из `Components.kt`.
Фон полей и блок ошибок также используют тему. Цвета и размеры шрифта на экранах
не задаются числовыми значениями.

JetBrains Mono Regular/Bold включён в APK: загрузка шрифта из сети не нужна.
Заголовки, основные надписи и основные кнопки — Bold, второстепенные тексты — Regular.
Все роли Typography используют этот шрифт. Источник шрифта — официальный
репозиторий JetBrains/JetBrainsMono, версия v2.304; лицензия в
`docs/licenses/JetBrainsMono-OFL.txt`.

Числовые размеры текста, интерлиньяж и отступы на переданном UI-kit отсутствуют.
Размеры Typography сохранены из Material, прежние отступы 16/10/8 dp вынесены
в StudySpacing. Скругления 8/16/20 dp — предварительные, требуют просмотра design.

В UI-kit показана только светлая тема. Она используется и при системной тёмной
теме; динамические цвета Android отключены, чтобы не заменять палитру Figma.
Отдельная тёмная тема в эту задачу не входит.

Это применение темы к существующим трём экранам, а не реализация загрузки TXT
или серверного списка режимов. Навигация, валидация и повтор запросов сохранены.

Проверка: `assembleDebug testDebugUnitTest lintDebug assembleDebugAndroidTest`,
затем StudyFlowUiTest и ResultContentTest на эмуляторе. UI-тест сохраняет три PNG в external files
приложения: theme-material.png, theme-modes.png, theme-result.png.
Список пяти режимов и ответ результата в UI-тесте — заглушки, LLM не вызывается.

Тема совмещена с задачами #19/#20 из main: сохранены загрузка режимов,
фиксированная область кнопок результата, прокрутка и переход к новому материалу.
Кнопка копирования и отступы ResultContent также используют тему.

Перед закрытием #23 дизайнер должен посмотреть три скриншота и предварительные
размеры. Отдельно требуется проверить читаемость пары текста ошибки #D94B78
на фоне #EEC1D5: значения перенесены из UI-kit без изменения.
